# Student Dashboard

The Student Dashboard is a web application designed to help manage student academic records efficiently. It allows users to add, view, edit, and delete student details, as well as search for students by roll number. The interface is user-friendly and visually appealing, making it easy to navigate and operate.

## Features

- **User Authentication:**  
  Users must log in or sign up to access the dashboard, ensuring data privacy and security.

- **Add Student Details:**  
  Fill out a form to enter student information, including name, registration number, department, semester, subjects, and marks. The total marks and percentage are calculated automatically.

- **View All Students:**  
  See a list of all students with their basic details. You can view more information, edit, or delete any student record.

- **Search by Roll Number:**  
  Quickly find a student’s academic details by entering their department, semester, and roll number.

- **Edit and Delete Records:**  
  Update student information or remove records as needed, with confirmation prompts to prevent accidental changes.

- **Responsive Design:**  
  The dashboard is styled for both desktop and mobile devices, ensuring a smooth experience on any screen size.


## How to Use

1. **Open the Dashboard:**  
   Start by opening `Home.html` in your browser. If you are not logged in, you will be redirected to the login page.

2. **Login or Sign Up:**  
   - Enter your username and password to log in.
   - If you don’t have an account, switch to the sign-up form and create one.

3. **Add Student Details:**  
   - Click the "Add Details" button.
   - Fill in the student’s information and submit the form.
   - The dashboard will calculate total marks and percentage automatically.

4. **View All Students:**  
   - Click "All Students Details" to see a table of all student records.
   - Use the "View" button to see full details, or the "Edit" and "Delete" buttons to modify or remove a record.

5. **Search by Roll Number:**  
   - Click "View By Roll_No".
   - Enter the department, semester, and roll number to find a specific student.

6. **Logout:**  
   - Use the profile dropdown in the header to log out securely.

## Technologies Used

- **HTML5 & CSS3:** For structure and styling.
- **JavaScript:** For interactivity and data management (using `localStorage` for persistence).
- **Responsive Design:** Ensures usability on all devices.



## Notes

- All data is stored in the browser’s local storage, so it is not shared between different browsers or devices.
- The application is intended for demonstration and educational purposes.
