# Multi-Page-Portfilo App (React+MUI):
A responsive, modern, and fully functional multi-page portfolio built with **React**, **Material UI (MUI)**, and **React Router DOM**. Features include  protected routes, and interactive components.

## Feature:
1. **Protected Routes** (e.g., Projects page only accessible after login)
2. **Multi-page navigation** using React Router
3.  **Light/Dark Mode** toggle using React Context API
4.  **User Authentication** with global state
5. **Reusable Components** with clean layout and animations

##  Tech Stack

- **React** – Frontend framework
- **React Router DOM** – Routing
- **Material UI (MUI)** – UI Components
- **JavaScript (ES6)** – Programming language
- **localStorage** – Client-side persistence
- **Context API** – Global state management

## React Routers:

/ - Home
/ about - About Page 
/projects - Projects (Protected)
/ COntact- Conact page
/profile - User Profile
/login - Login Page

## Theme Toggle:
Toggle between light and dark themes from the navbar using MUI icons. The theme choice is saved in localStorage.


##  Authentication
Simple login/logout simulation using context and localStorage. Future improvements could include Firebase or JWT-based auth.
