## What is ECMAScript?

**ECMAScript (often abbreviated as ES)** is a standardized scripting language specification that serves as the foundation for JavaScript. It was developed by ECMA International to ensure that different web browsers and environments implement JavaScript in a consistent way.

### Key Points about ECMAScript

- **Standardization:** ECMAScript defines the core features and syntax of JavaScript, making sure the language behaves the same across different platforms and browsers.
- **Versions:** ECMAScript has several versions, such as ES5, ES6 (also known as ES2015), ES7, etc. Each version introduces new features and improvements to the language.
- **New Features:** For example, ES6 introduced features like `let` and `const` for variable declarations, arrow functions, classes, template literals, and more.
- **Compatibility:** Modern JavaScript engines (like those in Chrome, Firefox, and Node.js) implement the ECMAScript standard, so code written according to the standard will work reliably across environments.

### Why is ECMAScript Important?

- It ensures that JavaScript code runs the same way everywhere.
- Developers can use new language features as they are standardized.
- It helps browser vendors and JavaScript engine developers keep their implementations up to date.

**In summary:**  
ECMAScript is the official standard that defines how JavaScript works. JavaScript is the most popular implementation of ECMAScript.


### variables in js   ###

Keyword	   Scope Type	     Reassignable         	Hoisted?	Notes

let      	Block-scoped	        Yes	                No	  Recommended for reassignable values
const    	Block-scoped	         No	                No	   Recommended for fixed values
